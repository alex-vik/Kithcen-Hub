# Food Manager — домашний склад продуктов

Личное PWA для учёта домашних запасов: система ведёт журнал расхода, прогнозирует потребление и к выходным сама собирает список покупок. Один пользователь, один дом.

Этот пакет — перенос работы из чата в Claude Code. Кода ещё нет: здесь спецификация, решения, дизайн и настроенная команда агентов.

## Что внутри

```
CLAUDE.md                     правила проекта, инварианты, поток задач — читает каждый агент
.claude/settings.json         главная сессия запускается как delivery-lead
.claude/agents/               delivery-lead (оркестратор) + analyst, architect, tester,
                              backend-dev, frontend-dev, reviewer
.claude/hooks/                запрет записи вне своих папок; запрет завершать работу при красных тестах
docs/spec.md                  спецификация требований v1.1 (FR, BR, NFR, тестирование, параметры)
docs/questions.md             бэклог вопросов на решение владельца, у каждого есть рекомендация
docs/design/style.md          визуальная система: токены, стекло, состояния кнопок, сетка
docs/design/prototypes/       исходники шести экранов-прототипов
docs/tasks/_template.md       шаблон задачи
docs/adr/                     архитектурные решения (пусто, заполнит architect)
docs/vision/summary-deck.html сводка решений в виде слайдов, открывается в браузере
```

## Как начать

1. Распаковать в пустую папку, `git init`, первый коммит.
2. Установить `jq` — на нём работают хуки. Без него хук границ блокирует запись.
3. Запустить `claude` в папке и отметить её как доверенную, иначе хуки агентов не сработают.
4. Сессия стартует как delivery-lead. Первым делом он пройдёт с тобой P1-вопросы из `docs/questions.md`.
5. Затем architect готовит ADR-001…005 (стек, СУБД, проекция остатка, модули, фоновые задачи) и файл `.claude/test-command`.
6. Дальше задачи идут по порядку сборки из CLAUDE.md: журнал событий → синтетический дом → прогноз → калибровка → API → экраны.

Команды владельца: «статус», «следующая задача», «что ждёт моего решения».
