Домашний склад продуктов

Чтобы дома всегда было нужное количество нужных продуктов — и закупка складывалась сама.

Личное приложение для одного дома. Сводка решений по итогам брейншторма.

Объём и фазы

Первая версия

Всё приложение целиком: учёт, киоск, приход, список покупок, пересмотр, рецепты и меню на неделю. Приоритеты в бэклоге — порядок сборки, а не граница выпуска.

Вторая фаза

Интеграция с доставкой: система собирает корзину в магазине, оплату подтверждает человек.

Каталог — около 150–200 позиций, один пользователь.

Как устроен учёт

Остаток — сумма событий

Числом он не хранится, а складывается из журнала. Любую ошибочную отметку можно откатить.

Расходная единица

Упаковка переводится в неё коэффициентом: пачка кофе — граммы, коробка капсул — штуки.

Один продукт

Молоко в литре и в поллитре — одна позиция. Разный только объём прихода.

Разные продукты

Разная расходная единица — разные позиции. Кофе в пачке и в капсулах живут отдельно.

Три типа списания

Ритмичные

Кофе, молоко, хлеб, корм. Списываются автоматически по норме каждый день.

Рывковые

Крупы, соусы, консервы. Только по отметке или по рецепту.

Медленные

Соль, масло, специи. Не списываются: к концу ожидаемого срока упаковки всплывают в колокольчике.

Тип система выставляет сама по истории покупок и расхода.

Нормы и самокалибровка

Нормы

Предлагаются при первом запуске, живут в карточке продукта, правятся вручную. Вручную отмечается только отклонение — вторая чашка кнопкой.

Опрос об остатке

На старте система спрашивает, потом вопросы затухают и возвращаются только при аномалии. Не больше 2–3 за раз, ответ грубый: много, мало, кончается.

Вычёркивание из списка

Сигнал «дома больше, чем я думала»: поднимает оценку остатка и смягчает норму.

Остаток ушёл в минус

Не ошибка, а подсказка: уверенность падает, позиция поднимается на пересмотре, норма пересчитывается.

Рецепты и меню на неделю

План блюд на неделю→ Ингредиенты в список→ «Приготовил»→ Сверка в четверг

Рецепт — шаблон списания

Снимает всё по номиналу, без правки граммовок. Замены и пропуски не выясняются — мелкие расхождения допустимо теряются.

Импровизация

«Списать блюдо» голосом: система разбирает на ингредиенты и после всегда предлагает сохранить рецепт.

Пересмотр в четверг

Главный экран. Не момент времени, а задача, которая висит до закупки. Напоминание повторяется в субботу.

Базовый режим

Только спорное — 5–7 строк, минута.

Детальный режим

Весь список с обоснованием. Выбор режима запоминается.

Сюда стянута вся калибровка: позиции с низкой уверенностью выше, сверка меню, подбивка расхождений.

Уведомления и колокольчик

Два повода для уведомления

Пересмотр в четверг вечером и красная позиция вне цикла. Жёлтые отдельно не шлются.

Колокольчик — открытые дела

Не архив уведомлений: пересмотр не пройден, красные позиции, блюдо не отмечено, сессия магазина протухла. Пункт уходит по выполнении.

Отпуск задаётся кнопкой с датами, заранее или задним числом — автосписания за эти дни отменяются.

Жизненный цикл позиции

Новая→ Активна→ Неактивна

Появилась

Система предлагает задать норму. Отказался — вернётся позже с готовым предложением. Сама не выставляет.

Перестали покупать

На пересмотре предложение: отключить, понизить норму или оставить. Решает человек.

Неактивна

Кнопка «больше не покупаю» или полгода без покупок. Состояние одно, повод — в журнале.

Техническая основа

Веб-приложение

PWA, одна кодовая база. Хостинг на ВПС — доступ нужен из магазина.

Распознавание

Голос и фото через облачные API крупных провайдеров, не локальные модели.

Стиль — стекло

Полупрозрачные поверхности, много воздуха, цвет работает на светофор. Размытие только на панелях.

Открыто

PostgreSQL или SQLite — на таком объёме непринципиально.

Вторая фаза: закупка в Barbora

Пересмотр→ «Оформить»→ Playwright собирает корзину→ Оплату жмёт человек

Почему браузер

Открытого API нет. Автоматизация страницы переживает больше изменений, чем внутренние эндпоинты.

Привязка товаров

Вручную, по одной, в момент первого заказа позиции. Дальше связь запоминается.

Надёжность

Фоновая задача, пропуск отсутствующих товаров, скриншот при падении.
