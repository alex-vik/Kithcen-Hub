# Бэклог поставки

Черновик разбиения первой версии на задачи по порядку сборки из CLAUDE.md. Это карта, а не задачи: analyst превращает строку в `docs/tasks/T-NNN-<slug>.md`, когда до неё доходит очередь, и может дробить или объединять. Номера T-NNN присваиваются при оформлении, здесь — рабочие метки `B-NN`.

Колонка «Вопросы» — значения по умолчанию из спеки, которые владелец должен подтвердить до начала задачи (`docs/questions.md`). Задачи без вопросов в колонке не ждут никого.

Ведёт delivery-lead: при оформлении задачи ставит её номер в колонку «Задача», при закрытии — «done».

Сквозные требования не имеют своей задачи и проверяются в каждой: NFR-04 (без офлайна), NFR-07 (мягкая деградация — сценарии симулятора), NFR-16 (чистый домен — ревью).
