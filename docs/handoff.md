## Как работали (практика, проверенная в этой сессии)

- Каждое поручение — по шаблону промпта delivery-lead; subagent не видит разговор.
- tester проверяет свои тесты мутантами на эталоне в scratchpad; reviewer гоняет свой набор мутантов — это поймало реальные дыры в 5 задачах из 12.
- Коммиты по зонам: tests / src / docs / память ревьюера отдельно (reviewer проверяет границы записи по коммитам).
- Незаконченную работу субагента не коммитить, пока он не отчитался (Stop-хук git-check можно игнорировать в этот момент).
- При лимите API субагент обрывается без отчёта: проверить `git status`, закоммитить частичное как WIP и перезапустить с пометкой «начни с ревизии».
