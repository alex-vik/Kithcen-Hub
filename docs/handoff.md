## Окружение

- Контейнер по умолчанию даёт Node 22. Node 26 ставится через nvm и подключается ссылками в `/root/.local/bin` (стоит в PATH раньше `/opt/node22/bin`). Если setup-скрипт окружения ещё не обновлён — выполнить:
  ```bash
  . /opt/nvm/nvm.sh && nvm install 26
  for b in node npm npx; do ln -sf "$(dirname "$(nvm which 26)")/$b" /root/.local/bin/$b; done
  npm install
  ```
- В режиме auto классификатор разрешений дважды надолго отказывал без вердикта; в режиме accept edits Bash и агенты работают.
