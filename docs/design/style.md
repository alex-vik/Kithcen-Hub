# Визуальная система

Источник правды для внешнего вида. Реализация экранов (frontend-dev) следует этому документу; интерактивные прототипы лежат в `prototypes/` и на холсте:
https://claude.ai/artifact/CFo9oSEg8AzvFD3nWEwTLh

Основа — светлый монохром с одним синим акцентом (референс «Augen Pro»), поверх — «жидкое стекло» для поверхностей и кнопок (референс — пункт управления macOS).

## Токены

```css
:root {
  /* цвет */
  --canvas: #e3e6eb;          /* фон страницы; чуть глубже белого, чтобы читались кромки стекла */
  --ink: #0f1012;             /* основной текст, тёмные поверхности */
  --muted: #4a4d52;           /* вторичный текст, не светлее — контраст на стекле */
  --disabled: #8f8f8f;        /* зачёркнутое, неактивное */
  --white: #fdfdfd;           /* активный диск, выбранное состояние */
  --accent: #0071e3;          /* только текст, иконки и контуры; никогда не заливка */

  /* статусы — только маленькие точки 10px, подпись всегда текстом рядом */
  --status-buy: #C8372D;      /* Купить */
  --status-soon: #E6A23C;     /* Скоро */
  --status-ok: #3A9A6A;       /* Есть */

  /* шрифт */
  --font: 'Inter', ui-sans-serif, system-ui, -apple-system, 'Segoe UI', sans-serif; /* замена PP Neue Montreal */
  --tracking: -0.02em;
  --weight-text: 350;         /* весь текст */
  --weight-control: 500;      /* только подписи на кнопках и активные элементы */

  /* размеры текста */
  --text-caption: 12px;       /* подписи секций */
  --text-meta: 13px;
  --text-body: 16px;
  --text-sub: 18px;
  --text-heading: 27px;       /* заголовок экрана на телефоне */
  --text-kiosk-title: 40px;
  --text-kiosk-action: 52px;

  /* скругления */
  --r-pill: 9999px;           /* кнопки, чипы, навигация, теги */
  --r-card-phone: 36px;
  --r-card-kiosk: 54px;
  --r-tile: 36px;

  /* отступы */
  --page-x-phone: 20px;
  --card-x: 22px;             /* внутренний отступ карточки = отступ подписи секции */
  --gap: 22px;
}
```

Шрифт подключается с альтернативными глифами: `font-feature-settings: "cv11" 1, "ss01" 1`.

## Поверхности

**Фон** — `--canvas` плюс 3–4 размытых световых пятна одного оттенка (`rgba(0,113,227, 0.10–0.34)`, `filter: blur(60–90px)`). Пятна нужны, чтобы стеклу было что размывать. Других цветов в фоне нет.

**Стеклянная панель** (карточки, списки, панель киоска):

```css
background: rgba(255,255,255,0.2);
backdrop-filter: blur(40px) saturate(1.8);
border: 0.5px solid rgba(255,255,255,0.9);
box-shadow: inset 0 0 0 0.5px rgba(0,0,0,0.05), inset 0 1px 0 #fff;
```

Без внешних теней. Разделители строк — `0.5px solid rgba(0,0,0,0.08)`, под последней строкой разделителя нет.

## Кнопки

**Стеклянная кнопка** — капсула или круг с толстой кромкой:

```css
background: rgba(255,255,255,0.16);
backdrop-filter: blur(24px) saturate(1.8);
border: 1px solid rgba(255,255,255,0.6);
box-shadow:
  inset 1.5px 1.5px 1px rgba(255,255,255,0.85),   /* блик сверху-слева */
  inset -1px -1px 1px rgba(255,255,255,0.35),     /* отражённый свет снизу-справа */
  inset 0 0 14px rgba(255,255,255,0.25),          /* внутреннее свечение */
  0 8px 18px -12px rgba(15,16,18,0.35);           /* мягкая опора, чтобы капсула не проваливалась */
```

Крупные плитки киоска — то же, радиус 54px, внутреннее свечение 24px.

**Состояния:**

| Состояние | Вид |
| --- | --- |
| Активное / главное действие | Белый диск `--white` с синей иконкой `--accent` внутри стеклянной капсулы |
| Выбранное (чип, сегмент, вкладка) | Белая капсула, синий текст, вес 500 |
| Второстепенное | Стеклянный диск без заливки, иконка `--ink` |
| Неактивное | Стеклянная капсула, текст `--ink` |
| Отметка в списке | Взято — белый диск с синей галочкой; не взято — стеклянное кольцо |
| Уведомление-тост | Тёмное стекло `rgba(15,16,18,0.62)`, белый текст, кнопка «Отменить» — светлая стеклянная капсула |

## Сетка и выравнивание

- Телефон: ширина 390, поля 20. Верхняя строка 48px (слева «назад», справа колокольчик), под ней подпись 13px и заголовок 27px в одну строку.
- Подписи секций, содержимое строк и вводный текст — на одном отступе 22px от края карточки.
- Нижняя навигация — плавающая стеклянная капсула, три вкладки: Пересмотр, Список, Дома.
- Киоск: 1194×834, поля 50. Шапка на всю ширину (дата и заголовок слева, дата закупки справа). Ниже две колонки 1.55 : 1, верх колонок на одной линии. У тоста зарезервирован ряд 64px — макет не прыгает.
- Цели нажатия не меньше 44px на телефоне и 56px на киоске.

## Запреты

- Синий не бывает заливкой.
- Статусные цвета — только точки; подпись статуса всегда текстом.
- Никаких градиентов и декоративных картинок, кроме световых пятен фона.
- Вес текста не выше 500.
- Размытие — только на панелях, карточках и кнопках, не на каждом элементе (NFR-10).
