# Прототипы

Интерактивный холст со всеми экранами: https://claude.ai/artifact/CFo9oSEg8AzvFD3nWEwTLh

Файлы `prototypes/*.dc.html` — исходники экранов холста. Они написаны в формате холста и сами по себе в браузере не запускаются: это эталон разметки, текстов, состояний и данных-примеров. Стили и правила — в `style.md`.

| Файл | Экран | Что показывает |
| --- | --- | --- |
| `Main.dc.html` | Киоск (планшет) | Списать → продукт → съел / закончилось / испортилось, тост с отменой; четыре способа прихода; виджет срочных покупок |
| `Review.dc.html` | Пересмотр | Базовый режим с вопросами калибровки и предложениями, детальный режим с обоснованием |
| `List.dc.html` | Список покупок | Отметки, прогресс, теги «с прошлой недели» и «по меню» |
| `Inventory.dc.html` | Что есть дома | Сортировка по срочности и по категориям |
| `Card.dc.html` | Карточка продукта | Остаток, уверенность, параметры учёта, события |
| `Bell.dc.html` | Открытые дела | Дела со ссылками, настройки |

Ещё не нарисованы: меню на неделю, рецепты, журнал действий, экран прихода на телефоне.
