## Контекст

NFR-16: доменная логика — чистые функции без БД, сети и системных часов, время — параметром. Без этого не работает симулятор (14.2): он прокручивает месяцы жизни дома за секунды и сравнивает результат с «реальным» расходом. Параметры раздела 15 спеки живут как конфигурация, а не как константы в логике (`CLAUDE.md`). Границы записи агентов заданы в `CLAUDE.md` и `.claude/hooks/guard-paths.sh`: backend-dev — `src/domain/`, `src/server/`; frontend-dev — `src/web/`; tester — `tests/`; architect — `src/` (каркас), корневые файлы сборки.

## Варианты

| Вариант | Суть | Оценка |
| --- | --- | --- |
| Слоистая «по технологиям» без правил зависимостей | `models/`, `services/`, `routes/` | Логика расползается по сервисам с доступом к базе; симулятор вынужден поднимать базу |
| Гексагональная архитектура с портами и адаптерами на каждый случай | Интерфейсы репозиториев внутри домена | Для одного хранилища и одного клиента — лишние абстракции |
| **Функциональное ядро, императивная оболочка** | Домен — данные на вход, решения на выход. Сервер читает из базы, вызывает домен, пишет результат | Минимум абстракций; домен тестируется и симулируется без инфраструктуры |

| Модуль | Может импортировать | Не может |
| --- | --- | --- |

| `tests` | всё | — |

### Что значит «чистый домен»

Функция домена зависит только от аргументов и возвращает результат; не читает часы, не ходит в базу и сеть, не генерирует случайность, не мутирует аргументы.

| Нельзя в `src/domain` | Вместо |
| --- | --- |
| `Date.now()`, `new Date()` без аргумента, `Temporal.Now.*` | `now: Temporal.Instant` параметром |
| `Math.random()`, `crypto.randomUUID()` | идентификаторы приходят извне: от клиента (BR-26) или от сервера аргументом |
| `process.env`, чтение файлов | `params` аргументом |
| константы раздела 15 в теле функций | поле `params`; значения по умолчанию — в `params.ts` |
| часовой пояс системы, `toLocaleString()` без пояса | `params.timeZone` = `Europe/Vilnius` (BR-27) |

Импорт `node:*`, `process`, таймеров и DOM ловит компилятор: `tsconfig.domain.json` собирает `src/domain` без `@types/node` и без DOM. Остальное из таблицы ловит reviewer. Рекомендация tester'у: в шаге 1 добавить в `tests/unit/` статическую проверку, которая ищет эти конструкции в `src/domain/**`.

Доменные функции — уровня сценариев, а не только формул. Всё, что симулятор должен воспроизводить (оценка остатка, темп, статусы, список покупок — BR-29, BR-30), — функция домена вида `(состояние, now, params) → решения` (оценки, статусы, список, положенные напоминания). Сервер для таких сценариев — тонкая обёртка: прочитать, вызвать домен, записать в одной транзакции. Иначе симулятор и сервер разойдутся.

### Время

- Система хранит моменты в UTC (NFR-14); домен получает `Temporal.Instant` и переводит в локальные даты через `params.timeZone`.
- Системное время читает только `src/server/clock.ts` (`now(): Temporal.Instant`). Обработчики и планировщик получают часы через `createApp(deps)` и параметры функций. Тесты подставляют фиксированные часы (14.4).
- Поведение не зависит от переменной окружения `TZ` и пояса контейнера.

### Параметры

`params.ts` описывает тип `Params` и значения по умолчанию из раздела 15 спеки, включая `timeZone`. Домен получает `params` аргументом. Сервер собирает `params` при старте (значения по умолчанию; механизм переопределения — когда появится первая настройка пользователя, Q-17). Тесты и симулятор передают свои `params`.

### Контракт клиент–сервер

Типы запросов и ответов живут в `src/server/http/` и описываются до экранов (B-16). Клиент импортирует их через `import type`. Использовать ли типизированный клиент Hono `hc` — решается в API-контракте.

## Последствия

- Домен тестируется без инфраструктуры; симулятор вызывает те же функции, что и сервер.
- Сервер содержит только ввод-вывод и транзакции; бизнес-правило в обработчике HTTP или в SQL — дефект ревью.
- Нужна дисциплина «сценарий = доменная функция»: reviewer проверяет, что в `src/server` нет ветвлений по бизнес-правилам.
- Структура каталогов совпадает с границами записи агентов; новый верхнеуровневый каталог в `src/` — только через architect.
